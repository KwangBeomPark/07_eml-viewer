# EML Viewer v0.1.18

Python/PySide6 기반으로 메일 열기와 첨부 작업을 개선하는 릴리스다.

- 첨부 열기·선택 저장·모두 저장 버튼을 고정하고 행 선택·더블클릭·키보드 이동을
  통일했다. 긴 파일명·확장자·선택 개수와 밝은/어두운 화면의 표시를 보완했다.
- 첫 화면, 아이콘 툴바, 간결한 메일 요약과 펼치는 상세 정보로 읽기 공간을
  확보했다. 작은 창의 상세 정보는 내부 스크롤을 사용한다.
- 창별 백그라운드 메일 읽기와 최신 요청 반영, 현재 폴더 목록 재사용,
  필요한 시점의 HTML renderer 초기화를 적용했다.
- EML 일괄 첨부 저장에서 중복 파싱을 줄였다. 선택 첨부 인덱스·CID 및 원본
  데이터·기존 MOTW/위험 파일 확인을 보존했다.
- 경고/확인창은 파일명을 HTML로 해석하지 않고, 화면용 숨은 방향 문자 표시와
  기본 ‘아니요’를 사용한다. 원본 메일·첨부 데이터는 표시 계층에서 바꾸지 않는다.

검수: Opus 5.5 설계·통합 검수와 Codex 최종 확인, 자동 회귀 및 source/offscreen
화면 검사를 수행했다. 한 차례 Qt 종료 검사 중단은 후속 전체 검사 및 합성 종료
경합 200회에서 재현되지 않았으며 원인은 확정하지 못했다. 설치형 Windows 종료·
Office 연결·고대비·Narrator·실제 프린터 검증은 별도다.

공식 자산은 새 버전 설치 EXE·매니페스트·SHA-256 목록 3개다. 실제 서명·게시
여부는 GitHub 릴리스와 해당 버전 매니페스트로 확인한다. 기존 사용자 설정 및
이전 버전 자산/태그는 보존한다.
